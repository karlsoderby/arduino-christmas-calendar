# Welcome to the Arduino Christmas Calendar 🎄

Behind every door hides a new surprise! Each day until Christmas, you open a door and get a **new exercise**, often with a **new component** to explore. Some days are quick, others are a bit more of a challenge, and they all build on what you learned the day before.

No peeking ahead! 🎅

## What Is the UNO Q?

The UNO Q has **two brains** on one board:

- A **Linux computer** that runs Python and can host web pages.
- A **microcontroller** that runs Arduino sketches and controls LEDs, buttons, sensors and motors.

The two talk to each other through the **Bridge**. You'll get to know both of them during the calendar.

## Get Ready

1. Download and install **Arduino App Lab** from [arduino.cc/en/software](https://www.arduino.cc/en/software).
2. Connect the UNO Q to your computer with the USB-C cable.
3. Open Arduino App Lab and follow the steps to set up your board.

## Import an App

Every day has a **Download App** button that gives you a `.zip` file. To import it:

1. Open any App in Arduino App Lab.
2. Select the arrow (**▼**) next to the App name near the top left corner.
3. Select **Import App**.
4. Drag and drop the `.zip` file into the import area, or select **Import from computer**.
5. Select **Open**, then click **Run**.
