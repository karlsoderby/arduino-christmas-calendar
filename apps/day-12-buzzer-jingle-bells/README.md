# Day 12 - Jingle Bells 🔔

Play the chorus of *Jingle Bells* on the Modulino Buzzer.

## You Need

- Arduino UNO Q
- Modulino Buzzer
- Qwiic cable

## Connect

Plug the Modulino Buzzer into the **Qwiic connector** on the UNO Q with the Qwiic cable.

## Run

1. Import the App into Arduino App Lab.
2. Click **Run**.
3. Sing along! The song repeats every few seconds.

## How It Works

- `melody[]` holds the note frequencies.
- `beats[]` holds how long each note lasts.
- Change `BEAT` to play the song faster or slower.
